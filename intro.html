Cloud Computing

Cloud computing means using computing resources such as servers, storage, databases, networking and software over the Internet instead of owning and maintaining them in a local data center. Users can rent exactly what they need, increase or decrease it within minutes, and only pay for what they use. This makes it cheaper and faster to start a project, because there is no need to buy expensive hardware. Cloud providers such as AWS, Microsoft Azure and Google Cloud also take care of maintenance, security updates and backups, so developers can focus on building their applications and reaching users anywhere in the world.

Cloud Services

IaaS

Infrastructure as a Service

Rent virtual servers, storage and networks. You manage the operating system and applications.

e.g. Amazon EC2

PaaS

Platform as a Service

A ready platform to build and deploy apps without managing servers yourself.

e.g. Google App Engine

SaaS

Software as a Service

Complete software used directly through the browser, with no install or maintenance.

e.g. Gmail
